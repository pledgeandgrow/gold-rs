# Internationalization (i18n) Design

> Goal 24 — Built-in i18n: compile-time message extraction, reactive locale switching, pluralization, date/number formatting, lazy-loaded translations, ICU MessageFormat support.

---

## Design Goals

- **Compile-time extraction** — Messages extracted from source at build time
- **Reactive locale** — Switching locale updates UI without reload
- **Type-safe** — Missing translations are compile-time warnings
- **ICU MessageFormat** — Industry-standard pluralization and formatting
- **Lazy loading** — Only load translations for the current locale
- **SSR-aware** — Server renders in the right locale

---

## Basic Usage

### Define messages

```rust
use rye::prelude::*;
use rye::i18n::{t, use_locale, Locale};

// Messages are defined inline — extracted at compile time
#[component]
fn Greeting() {
    let name = "World";

    div {
        // t! macro extracts message at compile time
        // and looks up translation at runtime
        h1 { {t!("Hello, {name}!", name = name)} }
        p { {t!("You have {count} unread messages.", count = 5)} }
    }
}
```

### Translation files

```
locales/
├── en.ftl          ← English (default)
├── fr.ftl          ← French
├── ja.ftl          ← Japanese
└── es.ftl          ← Spanish
```

### Fluent syntax (ICU MessageFormat)

```fluent
# en.ftl
hello = Hello, { $name }!
unread-messages = You have { $count ->
    [0] no unread messages
    [1] one unread message
    *[other] { $count } unread messages
}
welcome = Welcome back, { $name }. Last login: { $date }

# fr.ftl
hello = Bonjour, { $name } !
unread-messages = Vous avez { $count ->
    [0] aucun message non lu
    [1] un message non lu
    *[other] { $count } messages non lus
}
welcome = Bon retour, { $name }. Dernière connexion : { $date }
```

### Locale switching

```rust
#[component]
fn App() {
    let locale = use_signal(|| Locale::new("en"));

    // Provide locale to all children
    provide_context_signal(locale);

    div {
        // Language switcher
        select {
            value: {locale().code()},
            onchange: move |e| locale.set(Locale::new(e.value())),
            option { value: "en", "English" }
            option { value: "fr", "Français" }
            option { value: "ja", "日本語" }
            option { value: "es", "Español" }
        }

        // Content auto-updates when locale changes
        Greeting {}
    }
}
```

## t! Macro

```rust
// Simple message
t!("Hello, World!")

// With parameters
t!("Hello, {name}!", name = user.name)

// With pluralization
t!("{count} items", count = items.len())

// With explicit locale (overrides current)
t!("Hello", locale = Locale::new("fr"))

// With comment for translators
t!("Save", comment = "Button label for saving changes")
```

### Compile-time extraction

The `t!` macro extracts messages at compile time and generates a catalog:

```rust
// During build, the macro:
// 1. Collects all t!() calls
// 2. Extracts the message ID and parameters
// 3. Generates a message catalog (Rust code)
// 4. Checks for missing translations (warnings)

// Generated catalog (in build artifacts):
pub static MESSAGES: &[MessageEntry] = &[
    MessageEntry {
        id: "Hello, {name}!",
        params: &["name"],
        file: "src/greeting.rs",
        line: 12,
    },
    // ...
];
```

## Formatting

### Date formatting

```rust
use rye::i18n::format_date;

let date = chrono::Utc::now();

// Format using current locale
p { {format_date(date, "long")} }
// en: "January 15, 2026"
// fr: "15 janvier 2026"
// ja: "2026年1月15日"

// Custom format
p { {format_date(date, "yyyy-MM-dd")} }
```

### Number formatting

```rust
use rye::i18n::format_number;

// Decimal
p { {format_number(1234567.89)} }
// en: "1,234,567.89"
// fr: "1 234 567,89"
// de: "1.234.567,89"

// Currency
p { {format_currency(99.99, "USD")} }
// en: "$99.99"
// fr: "99,99 $US"
// ja: "¥100"

// Percentage
p { {format_percent(0.85)} }
// en: "85%"
// fr: "85 %"
```

### Relative time

```rust
use rye::i18n::format_relative_time;

// Time ago
p { {format_relative_time(Duration::minutes(5), Direction::Past)} }
// en: "5 minutes ago"
// fr: "il y a 5 minutes"
// ja: "5分前"

// Time from now
p { {format_relative_time(Duration::days(3), Direction::Future)} }
// en: "in 3 days"
// fr: "dans 3 jours"
```

## Lazy-Loaded Translations

```rust
// Only the default locale is loaded at startup
// Other locales are loaded on demand (code-split)

#[component]
fn App() {
    let locale = use_signal(|| Locale::new("en"));

    // When locale changes, the new translation file is loaded
    // The UI shows the old locale until the new one is loaded
    // (or shows a loading indicator via Suspense)

    Suspense {
        fallback: div { "Loading translations..." },
        // Translations are loaded automatically when locale changes
        Main {}
    }
}
```

### Build-time code splitting

```
dist/
├── app.wasm              ← core app (en translations bundled)
├── locales/
│   ├── fr.wasm           ← French translations (lazy-loaded)
│   ├── ja.wasm           ← Japanese translations (lazy-loaded)
│   └── es.wasm           ← Spanish translations (lazy-loaded)
```
